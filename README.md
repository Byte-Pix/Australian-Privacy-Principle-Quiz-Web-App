## What is the APP Quiz?
The Australian Privacy Principle Quiz (shortened as APP Quiz) is an educational quiz for 2026 Premier's Coding Competition's theme: Online Safety QLD.
APP Quiz is made purely with HTML, CSS, and Javascript.

## How to run
Open index.html in a browser. No server, framework, package manager or external library is required.

## What it does

The program presents 10 scenario based multiple choice questions. The user will be asked to identify which APP each question tests for and gives an explanation upon answering, whether the user was right or wrong. The quiz tracks the user's score and gives an evaluation at the end of the quiz.
